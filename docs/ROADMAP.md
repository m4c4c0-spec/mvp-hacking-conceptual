# Roadmap — Analyst Academy (18–32)

## MVP modelado (ahora)

- Oficina modular modelada en Unity → `Assets/Art/Office/Prefabs/Office_AnalystAcademy.prefab`
- `HubSceneRefs` + escenas `Hub` y `Hub_Art` conectadas al mismo modelo
- Carga Boot → bienvenida → introducción → primera persona, con progreso local
- uGUI/TMP en menú ESC + onboarding profesional, fuentes incluidas
- Refinamiento posterior de módulos en Blender según la guía de arte
- Playtest: `UnityTools/PLAYTEST_ETHICALLAB.md`

## Mes 2–3 — Producto jugable

- Pulir materiales PBR y set dressing
- +2 misiones solo en `missions.json`
- Credencial / mapa de progreso al cerrar 4 casos
- Localización EN (segundo JSON o campos duplicados)

## Mes 4–6 — Credibilidad

- Export expediente PDF/txt unificado
- Modo mentor vs auditor (`HubGuide`)
- Accesibilidad: remapeo, `reducedMotion`, tamaño UI
- Demo itch: tutorial + misión 01 gratis

## Mes 6–12 — Plataforma

- VR opcional (`XrInteractor` + XRI)
- Segunda locación (war room / datacenter ficticio)
- Kit educativo para profesores
- Store page con roadmap público (redes, forense light, IAM conceptual)

## Mes 12+ — Escala (si hay tracción)

- Editor de misiones con validación de esquema
- Mentor con voz (límites éticos revisados)
- Badge de completitud (sin prometer certificación profesional)
